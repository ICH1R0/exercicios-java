# Exercícios Java

Repositório com exercícios de fixação do curso **Java COMPLETO** (Udemy).

## Como está organizado

Cada exercício fica em sua própria pasta, com o nome descrevendo o que ele resolve.
Dentro de cada pasta há o projeto Java completo (pasta `src/` com os pacotes).

## Exercícios

| Pasta | Descrição |
|---|---|
| `conversor-moeda` | Lê a cotação do dólar e converte um valor em dólares para reais, aplicando 6% de IOF sobre o valor convertido. |
| `POO` | Exercícios de Programação Orientada a Objetos. |
| `funcoes` | Exercícios sobre métodos e funções. |

## Tecnologias

- Java
- IntelliJ IDEA
